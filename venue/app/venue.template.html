Publish a closed epoch

disclose(e) is permissionless and is the only write in the system whose purpose is to disclose. It spends budget to do it: the journal takes the coarser reading when the finer one is unaffordable, and emits nothing at all when neither fits. On an epoch that has not closed it returns without doing anything, so this control will not send one.

The disclosure record, on a consensus topic

Hedera Consensus Service

The venue’s meter withholds an event when a row’s budget is gone and lets the transaction stand, so a withheld disclosure and a quiet one are the same bytes in the log. That is the one thing a chain cannot report about itself. This stream reports it: an ordered, publicly readable topic that carries a positive record saying the venue acted and deliberately said nothing, on this row, against this budget.

No contract writes here, and none could: eth_getCode answers for 0x167 and for nothing else, so there is no consensus service system contract to call. HIP-478 specifies an oracle between the two services rather than a precompile, which is what tools/hcs-relay.mjs is. The operator holds the submit key and the topic has no admin key, so it cannot be deleted, renamed or reassigned. What the operator can do is stop, which the checkpoint series makes visible and nothing here can prevent.
