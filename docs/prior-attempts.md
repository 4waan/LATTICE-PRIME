# Prior attempts

Privacy was proposed for this network before. Understanding what happened to
those proposals shaped what this project attempts.

## What was asked for

Confidentiality for token holdings and transfers was requested several times
through the network's improvement process, within a short window, by different
parties. The requests were specific and the use cases were institutional.

## What shipped

Not those proposals. What shipped was a narrower counter-proposal that addressed
an adjacent problem and left the original requests open. The gap between what was
asked for and what exists is still there, and it is the gap this project sits in.

## The archival problem

Reconstructing this history was harder than it should have been, because the
record of the discussion does not preserve its own chronology reliably. Some of
what we wanted to cite had to be recovered from secondary sources.

## How much of this exists already

A census of zero knowledge work on this network found very little, and almost
none of it applied to regulated securities. The nearest comparable effort makes
essentially the same argument this project makes, in the same asset class, which
is reassuring about the premise and unhelpful about differentiation.

## What this establishes, and what it does not

It establishes that the problem is real, has been recognised by others, and
remains unsolved here. It does not establish that this approach is the right one.
That case has to be made by the implementation, not by the absence of
alternatives.
